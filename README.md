# نادا دورز | Nada Doors

موقع بورتفوليو (Portfolio) لمصنع أبواب **WPC** في مدينة الرياض — المملكة العربية السعودية.

موقع تعريفي عصري بصفحة واحدة (Single Page) باللغة العربية واتجاه من اليمين لليسار (RTL)، يعرض هوية المصنع ومنتجاته وأعماله ووسائل التواصل.

## المميزات

- 🎨 تصميم عصري بهوية لونية (أخضر زيتي + ذهبي) تليق بصناعة الأبواب الفاخرة.
- 📱 متجاوب بالكامل مع جميع الأجهزة (Responsive) مع قائمة جوال.
- 🌍 دعم كامل للعربية واتجاه RTL وخطوط Cairo / Tajawal.
- ⚡ حركات وتأثيرات خفيفة (Scroll Reveal + عدّادات إحصائية).
- 🧩 أقسام متكاملة: الرئيسية، من نحن، المنتجات، المميزات، معرض الأعمال، آلية العمل، آراء العملاء، نموذج تواصل/طلب عرض سعر.
- 🟢 زر واتساب عائم ونموذج تواصل تفاعلي.
- 🔍 محسّن لمحركات البحث (Meta + Open Graph).

## البنية

| الملف | الوصف |
|-------|-------|
| `index.html` | هيكل الصفحة والمحتوى |
| `styles.css` | التنسيقات والهوية البصرية والتجاوب |
| `script.js`  | التفاعلات (القائمة، الكشف عند التمرير، العدّادات، النموذج) |

## التشغيل

لا يحتاج الموقع إلى أي اعتماديات أو خطوة بناء. افتح `index.html` مباشرة في المتصفح،
أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التخصيص

- بيانات التواصل (الهاتف، البريد، العنوان) في قسم `#contact` داخل `index.html`.
- الألوان والهوية في متغيّرات `:root` أعلى ملف `styles.css`.
- نموذج التواصل حاليًا أمامي فقط؛ يمكن ربطه بخدمة بريد أو واتساب API لاحقًا.
