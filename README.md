# نادا دورز | Nada Doors

موقع تعريفي فاخر لمصنع **نادا دورز** المتخصص في تصنيع الأبواب الخشبية والمصفّحة والمدرّعة والذكية.

A modern, fancy, responsive marketing website for **Nada Doors** — a premium door
factory. Built with a UI/UX-driven design system (gold + charcoal luxury palette),
full RTL Arabic support, and smooth scroll-driven animations.

## ✨ المميزات / Features

- 🎨 هوية بصرية فاخرة بألوان العلامة (ذهبي + فحمي) — luxury brand-aligned palette
- 📱 تصميم متجاوب بالكامل (موبايل، تابلت، ديسكتوب) — fully responsive
- 🌐 دعم كامل للغة العربية واتجاه RTL — full RTL Arabic support
- 🚪 باب ثلاثي الأبعاد تفاعلي في الواجهة — interactive 3D hero door with parallax
- ⚡ حركات عند التمرير وعدّادات إحصائية — scroll reveals & animated counters
- 🧩 أقسام: الرئيسية، من نحن، المنتجات، المميزات، مراحل التصنيع، المعرض، آراء العملاء، تواصل
- 💬 زر واتساب عائم ونموذج طلب عرض سعر — floating WhatsApp + quote form
- ♿ يراعي `prefers-reduced-motion` وإمكانية الوصول — accessibility-aware

## 🗂️ البنية / Structure

```
index.html   # الصفحة والمحتوى / markup & content
styles.css   # نظام التصميم والأنماط / design system & styles
script.js    # التفاعلات / interactions
```

## 🚀 التشغيل / Run locally

لا يحتاج الموقع لأي أدوات بناء — افتح الملف مباشرة أو شغّل خادماً بسيطاً:

No build step required. Open `index.html` directly, or serve it:

```bash
python3 -m http.server 8000
# ثم افتح / then open  http://localhost:8000
```

## 🌍 النشر / Deploy

يعمل مباشرة على أي استضافة ثابتة مثل GitHub Pages أو Netlify أو Vercel.
Works on any static host (GitHub Pages, Netlify, Vercel) — just publish the root.

## 🎨 التخصيص / Customize

عدّل متغيرات CSS في أعلى `styles.css` لتغيير الألوان، وحدّث بيانات التواصل
وأرقام الهاتف والروابط في `index.html`.

Edit the CSS variables at the top of `styles.css` for colors, and update contact
details, phone numbers, and links in `index.html`.
